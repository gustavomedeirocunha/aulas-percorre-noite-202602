Html - HyperText Markup Language

O HTLM é uma linguagem de marcação de texto, ou seja, seu propósito é estruturar textualmente uma página da Web/Documento.

Estruturas ou Tags

Para estruturar um documento HTML ultilizamos tagas/elementos, po exemplp, para indicar que um texto é um paragrafo ultilizamos a tag < p> Texto de Parágrafo < /p> Existem tags que tema bertura < p> e fechamento < /p>, mas também existem tags "autofechantes" que não possuem fechamento, como a tag < img> de imagem.

Exemplo de tags:

  • p : parrágrafo
  • h1 : titulo principal
  • h2 : titulo secundario
